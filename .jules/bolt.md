## 2025-03-04 - [Optimize derived states with useMemo]
**Learning:** Using `useEffect` to synchronize derived state arrays (like filtered lists or calculated statistics) into a local `useState` variable is an anti-pattern that causes unnecessary cascading re-renders and hurts performance. Multiple sequential `Array.prototype.filter().length` calls for deriving specific categorical counts cause O(N*C) operations which can be expensive for large sets.
**Action:** Always compute derived states dynamically during rendering by wrapping the calculation in a `useMemo` hook. For multiple state categorizations, collapse multiple `filter` array iterations into a single O(N) `reduce` pass to improve performance and eliminate redundant execution overhead.
