## 2026-08-15 - ARIA labels for icon-only navigation buttons in AnnouncementBanner\n**Learning:** Interactive controls that rely solely on icons (like Chevrons for pagination or 'X' for dismiss) are completely opaque to screen readers and lack visual hover tooltips for sighted users. The AnnouncementBanner component's navigation buttons were missing these descriptive labels.\n**Action:** Ensure all interactive elements, particularly icon-only buttons like navigation arrows and dots, explicitly include `aria-label` (for screen readers) and `title` (for visual hover tooltips). For list-based controls like pagination dots, dynamically generate the labels (e.g., `Go to announcement ${i + 1}`) to maintain clear context.
